# AMS 3-Color Printing Guide

## Ready-to-Print Files

- `cad/out/bath_boat_mk2_ams3color_B.3mf` — Pattern B (Deep Green hull + Red band + White bridge, 5 swaps / ~5 g waste)
- `cad/out/bath_boat_mk2_ams3color_A.3mf` — Pattern A (Rescue Red hull + White + Deep Green, 4 swaps / ~4 g waste)
- `cad/slicer/hrx02_mk2_patternB_a1mini.gcode.3mf` — Pre-sliced for Bambu Lab A1 mini (`0.24mm Draft`, ~3h 17m, zero supports)

## Recommended Settings

- **Supports**: Disabled (`0`)
- **Walls / Infill**: `3` watertight wall loops / `15–20%` Gyroid infill
- **Microscopic G-code Audit**: All 6 bearing planes verified at `0.42 mm` extrusion width for full air-gap separation.
